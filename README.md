**MAZE ESCAPE** adalah game petualangan berbasis terminal yang dikembangkan menggunakan bahasa C++ dan library ncurses. Pemain harus menjelajahi labirin, menghindari monster dan jebakan, mengumpulkan item, serta menemukan jalan keluar untuk menyelesaikan setiap level.

## ✨ Features

- 🧩 2D maze exploration
- 👾 Monster enemies
- 💎 Collectible items
- 🪤 Traps and obstacles
- 🔊 Sound effects and background music
- 🏆 Multiple levels
- 🎨 Emoji-based terminal interface

## 🛠️ Built With

- C++
- ncurses
- paplay (audio playback)
- Ubuntu / WSL

## 🚀 How to Run

Compile the game:

```bash
g++ -std=c++17 -Wall -Wextra -o maze_escape main.cpp -lncursesw
```

Run the game:

```bash
./maze_escape
```

## 🎯 Objective

Explore the maze, collect important items, avoid enemies, and reach the exit to complete the game.
